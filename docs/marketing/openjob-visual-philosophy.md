# OpenJob 视觉理念：聚焦轨道

信息不应堆叠成压力，而应被重新组织成一条可执行的轨道。视觉以「散乱输入逐步收束」为核心：简历、岗位描述、代码、日历与问题卡片从不同方向进入，经过清晰的筛选节点，最终汇成今日任务。空间从左侧的多点分布过渡到右侧的稳定秩序，让观看者在几秒内感到“终于知道下一步做什么”。

形式采用克制的几何结构、明确的连接关系和大面积留白。圆点代表考点，连线代表学习路径，靶心代表有限时间下的优先级选择。每个元素都应经过细致校准，像一套由资深信息设计师反复打磨的导航系统，而不是装饰性的科技图案。

颜色以象牙白、深炭色和低饱和祖母绿为主。绿色只用于“行动、完成、关键路径”，其余信息保持中性，以减少认知噪音。材质保持平面、清晰、可靠，不使用炫目的渐变和夸张光效；专业感来自比例、间距和秩序，而不是视觉特效。

节奏上强调“诊断—规划—练习—复盘”的连续性。重复出现的小型节点形成稳定韵律，少量放大的目标形状建立视觉重心。构图需要体现大量精细劳动：线条粗细一致、图标语言统一、每一个对齐都像经过无数次校正，达到成熟产品品牌应有的工艺水准。

文字是视觉锚点而不是说明书。只保留 OpenJob、核心定位和极少量关键词，详细信息交给正文或真实产品截图。最终作品应像一张严谨又有人情味的路线图：不制造焦虑，而是把焦虑变成下一项可以完成的任务。
